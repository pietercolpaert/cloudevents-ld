# NL GOV profile for CloudEvents: case status change (NL)

The example event from Logius' [NL GOV profile for CloudEvents 1.1](https://gitdocumentatie.logius.nl/publicatie/notificatieservices/cloudevents-nl/1.1/), the Dutch government profile of CloudEvents. It is a notification that the status of a case (`zaak`) changed, sent by a population register (BRP) component.

The identifiers and personal data are fictitious. The BSN appears to be from the test range (9999…).

## Files

* `events.json`: the event, as a CloudEvents JSON batch with one event.
* `context.jsonld`: maps the producer-specific extension attributes, which CloudEvents does not define, to placeholder IRIs (prefix `nlgov:`, namespace `https://example.org/nlgov#`).
* `events.ttl`: generated by `npm run build:examples`, which applies [`../../context.jsonld`](../../context.jsonld) and `context.jsonld` to `events.json`. It conforms to [`../../shapes.ttl`](../../shapes.ttl).

## What this example shows

* **Extension attributes.**
  * `nlbrpnationaliteit` is a profile-specific extension. The example's own context maps it to `nlgov:nlbrpnationaliteit`.
  * `dataref`, `sequence` and `sequencetype` are documented CloudEvents extensions with their own predicates.
* **`null` means "not set".** `"geheimnummer": null` produces no triple. That matches the JSON event format, where `null` means an attribute is unset, and JSON-LD, which drops `null` values.
* **`source` as an organisation URN.** The source is `urn:nld:oin:…:systeem:…`, built from the organisation's OIN (Dutch organisation identification number). It is an absolute URI, as CloudEvents recommends.
* **`sequencetype` is lower case.** The example uses `"integer"`, whereas the CloudEvents v1.0.2 Sequence extension defines the value `"Integer"`. Our shapes only check `sequence` as an integer for `"Integer"`, so this event is not flagged.

The profile page has two more examples, but those are copied from the CloudEvents specification itself, so they are not repeated here.
